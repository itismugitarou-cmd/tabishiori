プライバシーポリシー

アクセス情報と保存データ

入力した旅の条件・保存したプラン・持ち物チェックは、お使いのブラウザ内(localStorage)にだけ保存され、運営者のサーバーには送信されません。

外部サービス

天気予報の取得に Open-Meteo、見どころ情報の取得に Wikipedia の API を利用しており、行き先の位置情報や地名がそれぞれのサービスに送信されます。

広告について

当サイトは、楽天アフィリエイト、Booking.com アフィリエイトパートナープログラムなどのアフィリエイトプログラムに参加しています。リンク先で予約・購入が行われた場合、運営者が紹介料を受け取ることがあります。これらのリンクには「PR」と表示しています。
